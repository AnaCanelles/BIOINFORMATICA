Ejercicio 1. Identificación aproximada de ortólogos

Los genes ortólogos son copias de un gen producidas por la divergencia de especies que descienden de un ancestro común. Si estas dos copias surgen por duplicación en una misma especies son parálogas entre ellas. Para estudiar la filogenia de especies se usan proteínas ortólogas, que permiten estudiar el tiempo que ha pasado desde la divergencia.

Para identificar si dos genes son ortólogos podemos combrobar si son su mejor resultado de BLAST mutuamente. En este ejercicio vamos a comparar los proteomas de Buchnera aphidicola (107806) y Blochmannia ocreatus (251538) y buscar proteínas ortólogas.

En primer lugar descargamos las secuencias de ambas especies desde uniprot.

Enmascarar e indexar los proteomas

if [ ! -e ../../data/2026-03-24/buchnera.paa ]; then
   # Creamos un archivo para enmascarar zonas de baja complejidad:
   if [ ! -e buchnera_seg.asnb ]; then
      segmasker -in ../../data/2026-03-24/buchnera.fa \
                -infmt fasta \
                -parse_seqids \
                -outfmt maskinfo_asn1_bin \
                -out ../../data/2026-03-24/buchnera_seg.asnb
   fi
   # Y indexamos el archivo FASTA para BLAST:
   makeblastdb  -in ../../data/2026-03-24/buchnera.fa \
                -input_type fasta \
                -dbtype prot \
                -parse_seqids \
                -mask_data ../../data/2026-03-24/buchnera_seg.asnb \
                -out ../../data/2026-03-24/buchnera \
                -title "Proteoma de Buchnera"
fi
if [ ! -e ../../data/2026-03-24/blochmannia.paa ]; then

Búsqueda de BLASTP

Para saber cuál es la proteína ortóloga de estas dos especies buscamos la proteína de Blochmannia ocreatus que más se parezca a las de Buchnera aphidicola y viceversa. De esta manera obtenemos una lista de proteínas que son recíprocamente las más similares de una especie a la otra, y estas son las más probables de ser ortólogas.

De Buchnera aphidicola hacia Blochmannia ocreatus

blastp -query ../../data/2026-03-24/buchnera.fa \
       -db ../../data/2026-03-24/blochmannia \
       -out buc2blo.txt \
       -outfmt '6 qseqid sseqid qlen slen length evalue bitscore' \
       -evalue 0.001 \
       -max_target_seqs 1
Warning: [blastp] Examining 5 or more matches is recommended

De Blochmannia ocreatus hacia Buchnera aphidicola

blastp -query ../../data/2026-03-24/blochmannia.fa \
       -db ../../data/2026-03-24/buchnera \
       -out blo2buc.txt \
       -outfmt '6 qseqid sseqid qlen slen length evalue bitscore' \
       -evalue 0.001 \
       -max_target_seqs 1
Warning: [blastp] Examining 5 or more matches is recommended

De esta manera obtenemos para el proteoma de cada especie una tabla en la que se relaciona cada proteína con la más similar de la otra especie. Algunas proteínas pueden tener más de un hit en la otra especie, así que tenemos que buscar las que tienen mayor coincidencia mutuamente, que serán las ortólogas.

NoteNota

Revisa los argumentos utilizados, prueba otros si quieres y asegúrate de que son adecuados. Puedes consultar la ayuda con blastp -help en el terminal.

-query identifica el archivo de entrada

-db indica la base de datos con la que se compara el archivo de entrada

-out da nombre al archivo de salida

-outfmt indica el formato que tendrá la tabla de salida y que información contiene cada columna

-evalue designa un valor límite a partir del cuál se guardan las coincidencias (0.001 en este caso)

-max_target_seqs define el número máximo de secuencias alineadas que queremos guardar (1 en este caso)

Comparación de resultados

A continuación creamos una tabla en R a partir de los archivos que acabamos de obtener con las comparaciones de proteomas. En las tablas de buc2blo y blo2buc se compara cada proteina de una especie con la de mejor coincidencia de la otra.

buc2blo <- read.table(
   'buc2blo.txt',
   col.names = c('query', 'subject', 'qlen', 'slen',
                 'length', 'evalue', 'bitscore')
)
blo2buc <- read.table(
   'blo2buc.txt',
   col.names = c('query', 'subject', 'qlen', 'slen',
                 'length', 'evalue', 'bitscore')
)
NoteNota

Echa un vistazo a estas tablas de resultados. ¿Sabrías identificar las parejas de proteínas que son recíprocamente la que más se parece una a la otra?

Añadimos a buc2blo una nueva columna llamada reverse con el nombre de la mejor coincidencia de la tabla blo2buc con la función match. De esta manera, comparamos si la mejor coincidencia de Buchnera a Blochannia es la misma que de Blochmannia a Buchnera. Después comparamos si la mejor coincidencia de Buchnera a Blochmannia es la misma que de Blochmannia a Buchnera y extraemos todas estas coincidencias a una nueva tabla, que contiene las posibles proteínas ortólogas.

buc2blo$reverse <- blo2buc[
   match(buc2blo$subject, blo2buc$query),
   'subject'
]
coincidencias <- buc2blo[
   buc2blo$query == buc2blo$reverse,
   c('query', 'subject')
]

Ejercicio 2. PSI-BLAST

En este ejercicio vamos a usar PSI-BLAST para identificar proteínas de una superfamilia pero que están alejadas. En este caso sus semejanzas son tan sutiles que no se encuentran con BLASTP, por eso necesitamos PSI-BLASTP.

P39615

# Como Swissprot debería estar ya descargada en `../../data`, podemos sacar
# de ahí la secuencia de la proteína escogida:
blastdbcmd -db ../../data/2026-03-24/swissprot -entry P39615 -out P39615.fa

# Y ahora la usamos como query en psi-blast:
psiblast -db ../../data/2026-03-24/swissprot \
         -query P39615.fa \
         -out P39615.blastout.txt \
         -evalue 0.1 \
         -outfmt 7 \
         -inclusion_ethresh 0.001 \
         -num_iterations 7 \
         -matrix BLOSUM62
Warning: [psiblast] Query_1 P39615.1 RecName:.. : Composition-based score adjustment conditioned on sequence properties and unconditional composition-based score adjustment is not supported with PSSMs, resetting to default value of standard composition-based statistics

A1AFY9

blastdbcmd -db ../../data/2026-03-24/swissprot -entry A1AFY9 -out A1AFY9.fa

psiblast -db ../../data/2026-03-24/swissprot \
         -query A1AFY9.fa \
         -out A1AFY9.blastout.txt \
         -evalue 0.1 \
         -outfmt 7 \
         -inclusion_ethresh 0.001 \
         -num_iterations 7 \
         -matrix BLOSUM62
Warning: [psiblast] Query_1 A1AFY9.1 RecName:.. : Composition-based score adjustment conditioned on sequence properties and unconditional composition-based score adjustment is not supported with PSSMs, resetting to default value of standard composition-based statistics
NoteNota

Consulta la ayuda de psiblast y asegúrate de entender para qué sirven los argumentos que hemos usado. Por ejemplo, ¿cuál es la diferencia entre -evalue y -inclusion_ethresh? ¿Cómo harías que la búsqueda fuera más sensible todavía?

-evaluecontrola el umbral de significancia para filtrar qué alineamientos se muestran en el reporte final, es decir, de los resultados encontrados solo se muestran aquellos que tienen un E-valor igual o menor que el indicado. El valor que hemos usado es de 0,1, que es más estricto.

-inclusion_ethresh controla las secuencias que se usan para construir la matriz, por lo que establece un límite sobre las secuencias que van a utilizarse. Define la evolución del perfil entre iteraciones. El valor que hemos usado, 7, es muy poco estricto.

Para aumentar la sensibilidad de la búsqueda podemos reducir el valor de -inclusion_ethresh, o incluso cambiar la matriz utilizada (en este caso BLOSUM62).
